# UNAIR SURUH (`@unair_suruh`)

> **Platform On-Demand Layanan Mahasiswa & Anak Kos di Surabaya**  
> Serba Bisa, Semua Disuruh! Cepat • Aman • Terpercaya.

Inisiatif mandiri mahasiswa di Surabaya untuk memenuhi kebutuhan harian anak kos, perantau, mahasiswa baru, organisasi kampus (Ormawa), dan masyarakat sekitar area Kampus A, B, dan C.

---

## 🌟 8 Lini Layanan (Care Series)

1. **Move Care** — Pindahan kos/kontrakan dengan Tossa, Mobil, atau Pick-Up + 1 Driver & 1 Helper.
2. **Keep Care** — Penitipan barang kos, koper, dan kardus saat libur semester, KKN, atau magang.
3. **Fix Care** — Deep cleaning kamar kos & KM dalam, perakitan furnitur (*knockdown*), dan servis teknis panggilan.
4. **Go Care** — Antar-jemput stasiun, bandara, kampus, dan bantuan darurat jalanan (motor mogok/ban bocor).
5. **Task Care** — Titip belanja kebutuhan kos, ambil/antar laundry & paket kilat, serta survei kos via video call.
6. **Desk Care** — Pengurusan administrasi kampus sah (ambil sertifikat ELPT, legalisir berkas dengan kuasa).
7. **Crew Care** — Tenaga kru operasional kegiatan BEM, Himpunan, UKM, wisuda (*setup*, *loading*, *clearing*).
8. **Talent Care** — Tutor sebaya akademik/olah data statistik (SPSS/R), fotografer wisuda, dan desain grafis.

## 🚀 Fitur Unggulan

- **Desain Modern & Ringan**: Terinspirasi dari alur konversi tinggi `kostcare.id` dengan visual elegan, responsif di semua perangkat mobile/desktop.
- **Form Pemesanan Cepat & Ramah**: 3 input simpel tanpa ribet login, langsung menghasilkan format chat WhatsApp yang sopan dan terstruktur.
- **TikTok Video Carousel & Real Reviews**: Menampilkan reel video dokumentasi kerja asli dari akun resmi `@unair_suruh` serta ulasan langsung dari komentar TikTok.
- **Web Admin Dashboard (`/admin.html`)**: Manajemen pesanan, katalog layanan, konten hero, dan manajemen video reel.
- **Female-Friendly & Safety**: Opsi penugasan khusus mahasiswi untuk pekerjaan di dalam kamar kos putri.

## 🛠️ Menjalankan Proyek Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/IrfanGG31/unair-suruh.git
   cd unair-suruh
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan di `http://localhost:5173/` dan dashboard admin di `http://localhost:5173/admin.html`.

4. **Build untuk produksi**:
   ```bash
   node build_clean_kostcare_unair.cjs
   ```
